# Fontes livres usadas pela interface moderna

Fontes com licença SIL Open Font License 1.1, que permite distribuí-las junto do port (cada pasta
traz o seu `OFL.txt`). Baixadas do repositório oficial do Google Fonts
(`https://github.com/google/fonts/tree/main/ofl/`).

| Pasta | Família | Pesos | Uso |
|-------|---------|-------|-----|
| `rajdhani/` | Rajdhani (Indian Type Foundry) | Light, Regular, Medium, SemiBold, Bold | texto do estilo de menu Modern (design system inspirado em 007 First Light) |

`hd_ui/fonts/` continua sendo a pasta das fontes do próprio usuário (fora do git).
